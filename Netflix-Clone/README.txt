========================================
  NETFLIX CLONE - Final HTML & CSS Project
========================================

A responsive Netflix-inspired landing page built with ONLY HTML5 and CSS3.
No frameworks (Bootstrap / Tailwind), no JavaScript.

----------------------------------------
FILE STRUCTURE
----------------------------------------
Netflix-Clone/
├── index.html          Main page (all 9 sections)
├── css/
│   └── style.css       All styling
├── images/             (poster art is generated with CSS gradients)
└── README.txt          This file

----------------------------------------
HOW TO RUN
----------------------------------------
Open "index.html" in any modern web browser (Chrome, Firefox, Edge, Safari).
No build step or server required. An internet connection loads the hero
background photo; every movie poster is drawn with pure CSS gradients so the
page still looks complete offline.

----------------------------------------
SECTIONS INCLUDED
----------------------------------------
1. Navigation Bar   - logo, 5 links, Sign In button, hover underlines
2. Hero Section     - background image, dark overlay, title, description,
                      Play + More Info buttons with hover animations
3. Trending Now     - 8 cards (CSS Grid) that enlarge on hover
4. Popular          - 8 different cards, shadows, rounded corners, hover
5. Continue Watching- poster + title + progress bar + remaining %
6. Top Rated        - numbered 1-10 with hover effects
7. Reasons to Join  - 4 icon/title/description cards
8. FAQ              - 5 expandable-style cards (expand on hover, CSS only)
9. Footer           - links, social icons, contact, copyright
